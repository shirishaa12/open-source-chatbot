# OpenSource Buddy AI

**Theme:** 2-B — Open-Source Contributor Guide

## Overview
OpenSource Buddy AI is a document-grounded question-answering assistant intended to help beginners understand open-source project documentation and contribution workflows. Users upload a document and ask questions in natural language. The application retrieves relevant passages and uses them as context for an answer.

## Problem
First-time contributors can find project documentation long, fragmented, and difficult to navigate. They may struggle to understand contribution steps or locate the right instructions.

## Solution
The assistant lets users ask questions about a selected document and presents an answer alongside retrieved passages. It should decline to answer when the document does not contain enough evidence.

## Features
- Document question answering
- PDF, Markdown (`.md`), and plain-text (`.txt`) ingestion **(verify each format before claiming complete support)**
- Retrieved passages shown to the user
- Source references where supported
- Handling of unsupported questions

## How to Run
1. Open the notebook in Google Colab.
2. Configure the required API key using Colab Secrets or the method specified in the notebook. Never publish the key.
3. Run the notebook cells from top to bottom.
4. Open the Gradio app link generated by the final cell.
5. Upload one supported document and ask questions about its contents.

## Evaluation
Test at least 15 questions across:
- Direct factual retrieval
- Comparison and multi-step questions
- Beginner onboarding guidance
- Questions whose answers are absent from the document
- PDF, Markdown, and TXT inputs

Record actual outcomes in `evaluation_results.csv` or a table in this README. Do not report unrun tests as passing.

## Limitations
Answer quality depends on text extraction, chunking, retrieval quality, and the language model. Always inspect the retrieved passages when evaluating an answer. PDF page references and text-file references may not have identical semantics.
